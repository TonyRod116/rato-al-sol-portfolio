# Glosario — Rato al Sol

- **Sol geométrico**: el modelo no detecta un obstáculo entre el punto y el sol.
- **Nubosidad**: previsión meteorológica separada de la geometría.
- **Terraza**: posición de las mesas, distinta de la puerta del negocio.
- **Sin cobertura**: no hay datos suficientes para clasificar ese lugar.

- **Verificado**: se aporta la comprobación del comportamiento concreto, no solo una salida cero.
- **Pendiente**: falta la evidencia o decisión indicada; no equivale a imposible.
