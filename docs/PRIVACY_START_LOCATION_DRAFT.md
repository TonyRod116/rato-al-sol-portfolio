# Borrador para actualizar la política de privacidad

Sustituir el apartado «Ubicación» de la política publicada por:

> **Ubicación.** Al abrir la aplicación, si lo permites, usamos la ubicación de tu dispositivo mientras la utilizas para centrar el mapa. También puedes usar el botón de ubicación para centrarlo. Si no das permiso, puedes mover el mapa manualmente. En Android, la búsqueda de una ciudad o dirección también puede solicitar el permiso de ubicación. Puedes cambiar o retirar el permiso en los ajustes del dispositivo.

Añadir al apartado «Datos guardados en el teléfono»:

> Para volver a la última zona consultada cuando no esté disponible la ubicación, conservamos en el dispositivo el centro aproximado del último mapa. Puedes borrarlo con el control «Borrar datos guardados» de la aplicación. Al usar el mapa de nuevo se puede guardar la nueva zona.

El área que se muestra y consulta para calcular sombras puede comunicarse a los proveedores que ya se describen en la política. Este borrador no se ha publicado ni sustituye la revisión de las prácticas de los proveedores.
